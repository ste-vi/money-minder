# Money Minder

A modern full-stack financial management web application built with Angular and Spring Boot, designed to help users track expenses, manage accounts, and gain insights into their financial habits.

## 🚀 Features

- **Dashboard Analytics**: Visual charts and insights using ApexCharts for expense tracking and financial overview
- **Account Management**: Create, update, and manage multiple financial accounts
- **Transaction Management**:
    - Add, edit, and categorize transactions
    - Search and filter transactions with advanced criteria
    - Review and approve transactions
    - Infinite scroll for large transaction lists
- **Category Management**: Organize expenses by categories with top expense tracking
- **MonoBank Integration**: Automatic transaction import from MonoBank API
- **PWA Support**: Progressive Web App with offline capabilities and update notifications
- **Responsive Design**: Material Design UI components for optimal user experience across devices
- **Authentication**: JWT-based secure authentication system

## 🛠️ Tech Stack

### Frontend
- **Angular 17.3.12** - Modern web framework
- **Angular Material 17.3.3** - UI component library
- **TypeScript 5.3.2** - Type-safe JavaScript
- **SCSS** - Enhanced CSS with variables and mixins
- **ApexCharts** - Interactive charts and data visualization
- **FontAwesome** - Icon library
- **PWA** - Progressive Web App capabilities
- **JWT Authentication** - Secure token-based authentication

### Backend
- **Spring Boot 3.4.1** - Java application framework
- **Kotlin 1.9.25** - Modern JVM language
- **Hibernate ORM 6.5.2** - Object-relational mapping
- **PostgreSQL** - Relational database
- **JWT** - JSON Web Token for authentication
- **GraalVM Native** - Native compilation support
